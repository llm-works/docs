# Open-source building blocks for production LLM agents

LLM Works is a Python platform of five packages: an application foundation, one client for every
model provider, typed LLM calls, a knowledge and learning layer, and an agent framework. Each
works on its own; together they take an agent from a first prototype to a service in production.

## Packages

<div class="grid cards" markdown>

-   :lucide-bot:{ .lw-card-icon }

    **[llm-gent](llm-gent/index.md)**

    Agents composed from traits, run standalone or behind an HTTP runtime.

-   :lucide-brain:{ .lw-card-icon }

    **[llm-kelt](llm-kelt/index.md)**

    Knowledge and learning: facts, feedback and retrieval in Postgres, and fine-tuning from them.

-   :lucide-braces:{ .lw-card-icon }

    **[llm-saia](llm-saia/index.md)**

    Typed verbs for LLM calls: verify, critique, extract and more, each with a typed result.

-   :lucide-cpu:{ .lw-card-icon }

    **[llm-infer](llm-infer/index.md)**

    One client for OpenAI, Anthropic, Google and OpenAI-compatible servers, plus a server for
    local models.

-   :lucide-layers:{ .lw-card-icon }

    **[appinfra](appinfra/index.md)**

    Application foundation: configuration, logging, CLI tools, services and PostgreSQL.

</div>
